# 桌面待办 · Desktop Todo

一个常驻桌面的浮窗待办清单。置顶、半透明、无边框，随时看得见，随手就能勾。

Python + tkinter 写的，**单文件、零第三方依赖**，装好 Python 双击就跑。

![截图](screenshot.png)

## 功能

**基础**
- 置顶 / 半透明 (0.92) / 无边框 / 标题栏拖拽 / 右下角缩放
- 任务：添加、编辑、删除、勾选完成（右键菜单）
- 优先级 高 / 中 / 低（红 / 黄 / 蓝圆点）
- 开始日期 + 截止日期，自动生成到期提醒：`今天开始` / `X天后开始` / `今天截止` / `剩X天` / `逾期X天`
- 按优先级排序，已完成自动沉底；鼠标滚轮滚动
- 底部状态栏：`共 N 项 · 完成 M 项`

**✨ 一键整理**
- 把一段原始信息（会议纪要、聊天记录、邮件原文、随手记）粘贴进去，点「整理」
- **两种模式自动切换：**
  - **没配 API Key** → **本地规则整理**：按行拆分、识别日期词（今天 / 明天 / 下周三 / 10月8日）、按关键词判优先级。**不联网、零成本、装上就能用。**
  - **配了 API Key** → 交给 DeepSeek：自动合并同类、判断优先级、补全日期，更贴近原意。
- 支持三种模式：只生成新任务 / 重新评估现有任务优先级 / 两者都要
- 可指定「任务归属人」，只提取与这个人相关的部分

## 快速开始

1. 装 [Python 3.8+](https://www.python.org/downloads/)（Windows 安装时记得勾 **Add Python to PATH**）
2. 下载本仓库全部文件
3. 双击 `启动桌面待办.bat`

也可以手动跑：

```bash
pythonw todo_desktop.py
```

任务数据存在同目录的 `tasks.json` 里，纯本地，不上传任何地方。

### 怎么填 API Key（可选，**不填也能用**）

**在软件里点标题栏的 ⚙ 就能填** —— 不用命令行、不用编辑器。

打开后把 Key 粘进去，点「保存」即可。Key 存在程序目录的 `config.json`，**只在本机、不上传、不进 Git**。

也可以手动配（适合批量部署）：

- 环境变量：`setx DEEPSEEK_API_KEY "sk-你的key"`
- 或 `~/.dsh/.credentials.yaml` 里写一行：`DEEPSEEK_API_KEY: sk-你的key`

Key 去哪儿申请：`platform.deepseek.com` → API keys

> **不填也行。** 点「✨ 整理」会自动用本地规则拆分条目、识别日期——只是不会做「合并同类」这种需要理解语义的事。

## 为什么做这个

桌面待办工具用了一圈，要么太重、要么要联网、要么弹窗干扰。想要的是那种「**一直在那里，但不烦你**」的感觉——所以做成半透明置顶浮窗，不抢焦点，抬眼就能看到今天还剩什么。
